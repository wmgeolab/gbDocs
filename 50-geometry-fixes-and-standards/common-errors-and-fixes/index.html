Common Errors and Fixes

This page helps identify common issues and directs you to the appropriate solution.

Cannot Edit Layer

Issue:
Cannot edit the layer.

Fix:
Turn on editing mode on the selected layer.

→ See: Editing Geometries

Gaps Between Polygons

Issue:
Empty spaces between adjacent boundaries (unless gaps do truly exist in the boundary).

Fix:
Align boundaries and ensure shared edges.

→ See: Editing Geometries
→ See: Topology and Validity

Overlapping Polygons

Issue:
Multiple polygons covering the same area, overlaps are never allowed.

Fix:
Remove overlaps and validate geometry.

→ See: Topology and Validity

Missing or Incorrect Fields

Issue:
Required fields are missing or incorrect.

Fix:
Standardize the attribute table.

→ See: Attribute Schema

Incorrect Projection

Issue:
Data is misaligned geographically.

Fix:
Reproject to WGS 1984.

→ See: Projecting the Shapefile

Missing Submission Files

Issue:
Required files are not included.

Fix:
Prepare complete submission package.

→ See: Exporting and Formatting

Extra Submission Files

Issue:
Extraneous files are included.

Fix:
Double check for a complete submission package.

→ See: Exporting and Formatting

Personal Information in Submission Files

Issue:
Personal information is included in the file name or the package.

Fix:
Ensure no personal information is in the submission package.

Summary

  • Identify the issue
  • Use linked guides for step-by-step fixes
  • Validate before submission
