# Issue Templates

This page explains how to use the geoBoundaries GitHub issue templates.

Issues are used to:
- Report problems with existing boundaries
- Request changes or fixes
- Suggest improvements or features

---

You can view all open issues here:

## Creating a New Issue

1. Navigate to the Issues page  
2. Click **New Issue**  
3. Select the appropriate template  

---

## Issue Template Options

The repository provides the following issue templates:

<img width="659" height="198" alt="image" src="https://github.com/user-attachments/assets/211ebfca-3c5e-494e-b4d5-37e7d2832913" />

### Boundary Errata
Use this template to report problems with an existing boundary.

Examples:
- Missing regions or polygons  
- Incorrect geometry  
- Attribute table errors  
- Outdated or incorrect data  

---

### Feature Request
Use this template to suggest improvements to the repository, workflow, or documentation.

Examples:
- Suggestions for new tools or processes  
- Improvements to documentation  
- Workflow enhancements  

---

### Blank Issue
Use this option if your request does not fit into the other templates. Input the problem with explicit details, and images if applicable.

---

## Filling Out an Issue

After selecting a template, complete the form with as much detail as possible:

### Guidelines

- Be clear and specific  
- Provide relevant links, sources, or images
- Describe the issue or request in detail  
- Follow the structure provided in the template

## Best Practices

- Search existing issues before creating a new one  
- Use the correct template  
- Provide enough detail for others to understand the issue  
- Include supporting information when possible  

---

## Summary

- Issues are used to track problems, requests, and improvements  
- Templates standardize submissions  
- Clear and complete issues improve workflow efficiency  

Using issue templates correctly helps maintain an organized and effective repository.
