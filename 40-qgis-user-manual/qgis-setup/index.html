QGIS Setup

In order to complete the necessary steps of georeferencing and digitizing for certain issues, QGIS must be downloaded onto an accessible computer.

The steps to download QGIS are listed at this website.

There are different downloading steps according to whether you are on a Windows, Mac, Linux etc. Ensure that each step is followed to be able to continue throught the QGIS User manual.
