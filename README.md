# geoBoundaries Documentation

Documentation in progress for [geoBoundaries](https://github.com/wmgeolab/geoBoundaries/).

This documentation side will provide
1. A clear, formal workflow for generating new boundaries - covering research strategies, sourcing/licensing/provenance, geometric fixes, QA/QC gates, packaging/release, and
2. A full user manual for doing the work in QGIS (step-by-step, screenshot-supported, repeatable by a new contributor).

[William & Mary geoLab](https://geolab.wm.edu/), the geoBoundaries Global Database of Political Administrative Boundaries Database is an online, open license (CC BY 4.0 / ODbL) resource of information on administrative boundaries (i.e., state, county) for every country in the world. Since 2016, we have tracked approximately 1 million boundaries within over 200 entities, including all UN member states. All boundaries are available to view or download in common file formats; the only requirement for use is acknowledgement.
